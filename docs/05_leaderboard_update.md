# 항만 문제해결을 위한 AI 기술 공모전 — 평가 데이터 및 리더보드 운영 방식 변경

> 보다 다양한 사례에서 모델 성능을 확인하고 본선 진출팀 선발을 위한 평가 변별력을 확보하기 위해, 기존 Public 평가 데이터를 포함한 **추가 데이터를 활용한 Private 평가**를 도입합니다.

---

## 공지 1. 평가 데이터 및 리더보드 운영 방식 변경 안내

### 1. 평가 데이터 및 리더보드 변경 사항

| 구분 | 기존 | 변경 |
|---|---|---|
| 평가 데이터 | **3,000건** | 기존 3,000건을 포함한 변경된 평가 데이터 |
| Public 평가 | – | 기존 3,000건을 포함한 변경된 평가 데이터 **일부**로 평가 |
| Private 평가 | – | Public 데이터가 포함된 데이터 **100%**로 평가 |
| 예선 최종 점수 | 대회 종료 시점의 **Public Score** | 최종 선택한 제출물의 **Private Score** |

- **학습 데이터와 선박 카탈로그는 변경되지 않습니다.**
- 데이터의 컬럼 구조와 제출 형식, 평가 산식은 기존과 동일합니다.

### 2. 변경 사항 적용 일정

| 일시 | 내용 |
|---|---|
| **10월 19일(월) 오전 11시 ~ 낮 12시 (1시간)** | 리더보드 초기화 및 Private 평가 적용 작업으로 리더보드 업데이트·코드 제출 **일시 중단** |
| **10월 19일(월) 낮 12시** | 변경된 평가 방식으로 제출 재개 예정 |

- 제출 횟수: **3 → 5회**로 상향합니다.

### 3. 최종 제출물 선택 안내

- 최종 평가에 사용할 제출물은 **1개**를 선택할 수 있습니다.
- 최종 제출물 선택은 **10월 23일(금) 낮 12시 적용 예정**입니다.
- 대회 종료 전 최종 평가에 사용할 제출물을 **반드시 선택**해 주세요.
- 최종 선택한 제출물의 **Private Score**와 **코드 검증 결과**를 바탕으로 본선 진출팀을 확정합니다.

### 4. 동점자 처리 기준

최종 평가 점수가 같으면 아래 순서로 우선순위를 정합니다.

| 순위 | 기준 | 내용 |
|---|---|---|
| 1 | **추론 시간** | 동일한 평가 환경에서 측정한 추론 시간이 짧은 팀 |
| 2 | **제출 파일 용량** | 최종 선택한 제출 ZIP 파일의 용량이 작은 팀 |
| 3 | **점수 달성** | 동일한 점수를 먼저 달성한 팀 |

## 공지 2. Private 평가 적용 및 제출 재개 안내

Private 평가 적용과 리더보드 초기화가 완료되어 **제출이 재개**되었습니다.

### 1. 평가 및 리더보드 운영

- **Public Score**: 기존 평가 데이터 3,000건을 포함한 평가 대상 일부의 점수입니다.
- **Private Score**: Public 평가 대상을 포함한 전체 채점 대상의 점수이며, **예선 최종 평가**에 사용됩니다.
- 학습 데이터·선박 카탈로그·제출 형식·평가 산식은 변경되지 않습니다.
- 초기화된 리더보드에서 점수를 확인하려면 **제출물을 다시 제출**해 주세요.

### 2. 실행 시간 및 제출 횟수

| 항목 | 변경 |
|---|---|
| 추론 제한 시간 | 20분 → **30분** |
| 일일 제출 횟수 | 3회 → **5회** |
| 패키지 설치 제한 시간 | **10분 유지** |

- 추론 코드는 행 수와 ID를 고정하지 않고, 서버의 `data/test.csv` **전체를 읽어** 예측해야 합니다.

### 3. 최종 제출물 선택 — 반드시 확인해 주세요

- 현재 최종 제출물 **1개를 선택**할 수 있으며, 선택한 제출물의 **Private Score와 코드 검증 결과**로 본선 진출팀을 확정합니다.
- **최종 선택 후 재제출하면, 최종 선택이 Public Score 기준 최고 점수 제출물로 자동 변경됩니다.** 추가 제출 후 최종 선택 상태를 반드시 확인해 주세요.
- **11월 2일(월) 오전 10시 이후에는 최종 제출물 선택·수정이 불가능합니다.** 모바일에서도 변경할 수 없습니다.
- 마감 직전에는 평가 대기열이 길어질 수 있으니, **미리 제출하고 평가 결과와 최종 선택까지 확인**해 주세요.
