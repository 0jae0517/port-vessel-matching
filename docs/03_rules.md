# 항만 문제해결을 위한 AI 기술 공모전 — 규칙

---

## 1. 개인 또는 팀 참여 규칙

- 개인으로 참여하거나 팀을 이루어 참여할 수 있습니다.
- **개인 참가 방법**: 팀 신청 없이 제출 탭에서 바로 제출할 수 있습니다.
- **팀 참가 방법**: 팀 탭에서 신청할 수 있으며, 자세한 내용은 팀 탭의 팀 병합 정책에서 확인합니다.
- **팀 구성 방법**: 팀 페이지의 팀 구성 안내를 확인합니다.
- **팀 최대 인원**: **5명**
- 같은 사람이 개인과 팀, 또는 여러 팀에 **중복으로 등록할 수 없습니다.**

---

## 2. 대회 규칙

- **추가 데이터 금지**: 모델의 추가 학습·검증에 쓸 수 있는 대회 데이터는 주최 측이 제공한 **`train.csv`와 `vessel_catalog.csv`로 제한**됩니다.
- 외부 선박 데이터베이스, 별도 입출항 기록, 외부 정답·매핑표 등은 **사용할 수 없습니다.**
- **사전학습 가중치 허용**: 공개된 **범용 사전학습 모델의 가중치는 사용할 수 있습니다.**
  - 단, 외부 선박 정답이나 별도 데이터셋을 이용한 추가 학습·검증은 금지됩니다.
- **평가 행 독립**: `test.csv`의 각 행은 **해당 행의 입력값과 공식 제공 데이터만으로** 예측해야 합니다.
  - 같은 Test 파일의 다른 행이나 전체 분포를 이용한 아래 방식은 허용되지 않습니다.
    - 평균·빈도·순위·그룹 투표
    - 누적 특징
    - 예측값 보정
- 같은 행은 Test 전체, 부분집합, 단독 행, 순서를 바꾼 상태 중 어느 것으로 실행해도 **예측값이 같아야 합니다.**
  - 운영진은 코드를 다시 실행해 이를 검증할 수 있습니다.
- 비공개 평가 데이터나 정답을 로그·제출 파일에 기록하거나, 외부로 전송·유출하는 행위는 **금지**됩니다.
- 대회 데이터는 본 대회 참가 목적에 맞게만 사용해야 하며, **원본 식별정보 복원**이나 **허가되지 않은 재배포는 금지**됩니다.

## 3. 코드 및 PPT 제출 규칙

- 추론 코드는 **Python**으로 작성합니다.
- `submit.zip` **최상위 경로**에 `script.py`와 `requirements.txt`를 넣고, 필요한 모델 파일은 `model/`에 넣습니다.
- `script.py`는 평가 서버의 아래 파일을 이용해 **`output/submission.csv`** 를 만들어야 합니다.
  - `data/test.csv`
  - `data/vessel_catalog.csv`
- 예선이 끝난 뒤에는 평가 대상 코드·모델을 **교체할 수 없습니다.**
  - 운영진은 재현성, 실행 규격, 데이터 사용 규칙, 참가 자격을 검증합니다.

## 5. 유의 사항

- **1일 최대 제출 횟수**: **3회**
- **사용 가능 언어**: Python
- 대회 직후 공개되는 Private 리더보드 랭킹은 **최종 순위가 아닙니다.** 코드 검증 후 본선 진출자가 결정됩니다.
- 코드 제출 기능을 악용해 평가 데이터셋을 의도적으로 유출하는 등 규칙 위반이 발견되면 **실격**됩니다.
- 평가 서버 환경(시스템 부하, 스케줄링 등)에 따라, **같은 제출물(추론 코드와 모델)이라도** 제출할 때마다 리더보드 추론 속도가 조금씩 다를 수 있습니다.
- 제출 시 평가 서버에서 **실제로 측정·기록된 리더보드 점수만** 공식 평가 결과로 인정합니다.
- 데이콘은 부정 제출 행위를 금지하며, 데이콘 대회에서 **부정 제출 이력이 있으면 평가가 제한**됩니다.
