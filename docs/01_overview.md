# 항만 문제해결을 위한 AI 기술 공모전 — 개요

> 주제: **AI를 활용한 선박 정보 표기 차이 해소**
> 입출항 기록과 표준 선박제원정보를 활용한 선박 정보 매칭 AI 모델 개발

---

## 1. 배경
- **항만 입출항 신고 기록**은 선박의 입항·출항 현황을 관리하고 항만 운영 데이터를 분석하는 데 쓰는 핵심 자료입니다.
- 그런데 입출항 기록의 선박 정보와 **표준 선박 제원정보**는 기준과 형식이 서로 다른 경우가 많습니다.
- 같은 선박이라도 아래와 같은 차이 때문에 **단순 문자열 비교로는 정확히 연결하기 어렵습니다.**
  - 한글·영문 표기 차이
  - 띄어쓰기·철자 변형
  - 약칭
  - 동명 선박
  - 톤수 오차
  - 일부 정보 누락
- 그래서 입출항 기록을 표준 선박정보와 연결하려면 확인 작업이 많이 필요합니다.
- 선박 정보를 정확히 매칭하면 **항만 데이터 통합·품질관리**와 **선박 특성 분석, 물동량 분석, 해운물류 정책 수립**의 기반을 마련할 수 있습니다.
- 본 대회에서는 불완전한 입출항 기록을 분석해 **표준 선박 제원 카탈로그에서 해당 선박을 식별하는 AI 모델**을 개발합니다.
- 개발된 모델은 정답 선박이 확인되지 않은 입출항 기록에 대해 **유력한 선박 후보를 추천**하고, 항만 데이터 정비 업무를 지원하는 데 활용될 수 있습니다.

---

## 2. 대회 방식

**온라인 예선**을 거쳐 **본선 발표평가**를 진행합니다.

### 2.1 온라인 예선
- 참가자는 **학습 데이터**와 **선박 제원 카탈로그**를 이용해 선박 매칭 모델을 개발합니다.
- **학습이 완료된 모델과 추론 코드**를 제출합니다.
- 제출한 코드는 **비공개 평가 데이터가 저장된 데이콘 평가 서버**에서 실행됩니다.
  - 따라서 코드 제출형 대회이며, 평가 데이터는 볼 수 없습니다.
- **온라인 예선 점수**를 기준으로 본선 진출팀을 선정합니다.

### 2.2 본선 평가
- 본선 진출팀은 다음 내용을 발표합니다.
  - 모델 개발 과정
  - 주요 방법론
  - 실험 결과
  - 현장 적용 방안
- **온라인 예선 성적 + 본선 발표평가 결과**를 종합해 최종 수상팀을 선정합니다.
- 본선 진출팀 수와 최종 평가 방법은 **추후 안내 예정**입니다.

---

## 3. 주제
- **AI를 활용한 선박 정보 표기 차이 해소**
- 입출항 기록과 표준 선박제원정보를 활용한 선박 정보 매칭 AI 모델 개발

---

## 4. 설명

| 항목 | 내용 |
|---|---|
| 입력 | 항만 입출항 기록 **한 행** |
| 출력 | 공개된 선박 제원 카탈로그에서 같은 선박의 **`vessel_id` 1개** |
| 과제 유형 | 레코드 매칭 / 엔티티 해석(Entity Resolution) |

- 입출항 기록의 선박 이름에 **철자 차이**가 있거나 **일부 제원값이 비어 있더라도**, 선박명과 나머지 제원정보를 **함께 고려해** 올바른 카탈로그 ID를 선택해야 합니다.

---

## 5. 참가 자격
- **국내외 고등학교·대학교(대학원) 재학생, 미취업자**
- ※ 공고일 기준 국내외 고등학교·대학(원)에 재학 중인 학생, 또는 **졸업 후 3년 이내의 미취업자**
