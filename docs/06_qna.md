## 1. LLM LoRA 미세조정 사용 여부 (2026-10-21 답변)

**질문 요지**
- 공개된 범용 사전학습 LLM의 가중치를 `submit.zip`에 동봉해 오프라인으로 추론하고, `train.csv`만으로 LoRA 미세조정해 사용해도 되는지

**답변 (원문)**

> (모)델을 LoRA 미세조정하고 필요한 가중치를 제출물에 포함해 오프라인 추론하는 방식은 허용됩니다. 외부 데이터·API를 사용하지 않고 각 평가 행을 독립적으로 예측해야 하며 코드 검증 시 학습·전처리·추론 전체 코드와 사용한 가중치를 함께 요청드릴 수 있습니다. 감사합니다.

**정리**
- ✅ LLM LoRA 미세조정 + 가중치 동봉 + 오프라인 추론 **허용**
- 조건
  - 외부 데이터·외부 API 사용 금지
  - 평가 행마다 독립적으로 예측
- 코드 검증 때 **학습·전처리·추론 전체 코드**와 **사용한 가중치**를 요청할 수 있음 → 최종 제출물의 재현 경로를 남겨 둘 것
