# 항만 문제해결을 위한 AI 기술 공모전 — 평가 방식

---

## 1. 리더보드

**평가 산식**

```
Score = 0.7 × 한글 기록 정확도 + 0.3 × 비한글 기록 정확도
```

- 한글·비한글 구분은 **평가 대상 기록의 선박명 표기**를 기준으로 합니다.

| 구분 | 평가 데이터 |
|---|---|
| **Public Score** | 기존 3,000건을 포함한 일부 데이터 |
| **Private Score** | 전체 테스트 데이터 100% |

- 예선 최종 순위는 **종료 시점의 공식 점수**를 기준으로 정합니다.
- 다만 아래 항목을 검증한 뒤 본선 진출팀을 확정합니다.
  - 제출 코드의 재현성
  - 실행 규격
  - 규칙 준수
  - 참가 자격

## 2. 평가 방식

- **온라인 예선**: 대회 종료 시점의 **Public Score** 기준
- **본선 진출**: 검증을 통과한 **예선 상위 6팀**이 원칙입니다.
  - 동점·포기·결격 등이 생기면 **최대 9팀 범위**에서 차순위팀을 검토할 수 있습니다.

> ⚠️ 1장은 "종료 시점의 공식 점수", 2장은 "Public Score"로 적혀 있습니다. 본선 '모델 성능' 항목은 Private 점수를 씁니다. 예선 순위가 Public과 Private 중 무엇을 기준으로 하는지는 공지나 Q&A로 확인이 필요합니다.

## 3. 코드 제출 대회 가이드

본 대회는 `submit.zip` 파일을 제출하는 **코드 제출 대회**입니다. (데이콘 기본 가이드 문서 참고)

### 3.1 제출 파일 구조 (`submit.zip`)

**디렉토리명과 파일명이 아래와 정확히 일치해야 합니다.**

```
submit.zip
├── model/              # 모델 가중치 파일을 저장하는 디렉토리
│   └── (예: model.pt 등)
├── script.py           # 실제 추론이 수행되는 실행 코드
└── requirements.txt    # 필요한 패키지 및 버전 명시
```

- `script.py`는 제출하면 평가 서버에서 **자동으로 실행**됩니다.
- `requirements.txt`는 `pip install -r requirements.txt`로 설치할 수 있어야 하며, 추론에 필요한 **모든 패키지**를 포함해야 합니다.
- zip 구조가 반드시 일치해야 합니다.
  - 예: zip 안에 **최상위 폴더가 하나 더 있으면** 설치 오류가 발생합니다.

### 3.2 평가 서버에서 자동 추가되는 항목

```
submit.zip
├── model/                    # 참가자 구성
├── script.py                 # 참가자 구성
├── requirements.txt          # 참가자 구성
├── data/                     # 평가에 사용될 테스트 데이터 (자동 생성)
└── output/submission.csv     # 참가자 추론 결과 저장 경로 (자동 생성)
```

- `data/`: 실제 평가 데이터를 포함한 대회 데이터가 들어 있으며, **읽기 전용**입니다(쓰기·수정 불가).
- `output/`: `script.py`가 만든 예측 결과를 저장하는 디렉토리입니다. 결과는 반드시 **`output/submission.csv`** 로 저장해야 합니다.

### 3.6 평가 서버 기본 설치 패키지

- 아래 패키지는 평가 서버에 **기본으로 설치**되어 있습니다.
- 버전이 명시된 패키지를 다른 버전으로 쓰면 **설치 에러가 날 수 있습니다.** 가급적 기본 설치 패키지를 그대로 쓰고, `requirements.txt`에는 **넣지 않는 것을 권장**합니다.
- 라이브러리 설치 에러는 **설치 오류**로 처리되며, 일일 제출 횟수에 반영되지 않습니다.

### 3.7 유의사항

**오류는 두 가지로 나뉘며, 일일 제출 횟수 반영 기준이 다릅니다.**

| 오류 종류 | 발생 조건 | 일일 제출 횟수 |
|---|---|:---:|
| 설치 오류 | `submit.zip` 내부 구조 불일치, 패키지 설치 오류 | ❌ 반영 안 됨 |
| 제출 오류 | `script.py` 실행 후 발생하는 **모든** 오류 | ✅ 반영됨 |

- `script.py`에서는 `open/` 디렉토리의 데이터를 읽고, 예측 결과를 반드시 **`output/submission.csv`** 로 저장해야 합니다.
  > ⚠️ 3.2절 구조에는 `data/`만 있으므로 `open/`은 `data/`의 오타일 수 있습니다. 확인이 필요합니다.
- 평가 서버는 인터넷에 접속할 수 없으므로, 패키지 설치 이후 **외부 다운로드가 필요한 코드나 모델은 작동하지 않습니다.**
