# 항만 문제해결을 위한 AI 기술 공모전 — 배포용 데이터 구조

---

## 1. 파일 구성

```
open.zip
├── train.csv               학습 입력 및 정답 데이터 (12,222행 × 9컬럼)
├── vessel_catalog.csv      선박 제원정보 및 예측 후보 목록 (78,595행 × 8컬럼)
└── sample_submission.csv   예측 결과 형식 확인용 (3,000행 × 2컬럼)
```

| 파일 | 용도 | 크기 |
|---|---|---|
| `train.csv` | 학습 입력 및 정답 데이터 | 12,222행 × 9컬럼 |
| `vessel_catalog.csv` | 선박 제원정보 및 예측 후보 목록 | 78,595행 × 8컬럼 |
| `sample_submission.csv` | 예측 결과 형식 확인용 | 3,000행 × 2컬럼 |

---

## 2. 별도 제공 파일

- **`baseline_submit.zip`**: 베이스라인 코드로 만든 **참고용 제출 파일**이며, `open.zip`과 별도로 제공됩니다.

---

## 3. 평가 데이터 (`test.csv`)

- 비공개 평가 입력인 `test.csv`는 **배포 파일에 들어 있지 않습니다.**
- 실제 평가 데이터는 **3,000행 × 8컬럼**입니다.
- 코드를 제출하면 평가 서버의 **`data/test.csv`** 경로에서 제공됩니다.

---

## 4. 제출 형식

- 참가자 코드는 각 행의 **`target_vessel_id`** 를 예측해 **`output/submission.csv`** 를 만들어야 합니다.
- `sample_submission.csv`에는 평가 대상의 **`sample_id` 3,000개**가 들어 있습니다.
- `target_vessel_id` 열의 값은 출력 형식 예시일 뿐 **정답이 아닙니다.**
